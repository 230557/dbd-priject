DBD Browser
Project overview
DBD Browser is a small real-time browser multiplayer game built with Express and Socket.IO. It has a shared lobby, a 1-killer/4-survivor match, generators, hooks, exits, chat, spectator mode, and configurable controls.

User preferences
Keep the game readable and playable in the browser.
Favor Dead by Daylight-inspired balance: one killer, four survivors, clear counterplay, and short-lived information rather than permanent tracking.
All gameplay systems should work for both human players and lobby bots.
